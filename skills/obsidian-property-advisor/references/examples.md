# Obsidian Property Advisor Examples

This reference documents standard usage patterns and example output modes.

## Output Modes Supported
1. **Markdown Note Only**: When the user simply asks for a note and no properties are needed.
2. **Property Proposal Only**: When the user explicitly wants schema recommendations for a domain.
3. **Markdown Note + Property Proposal**: A full note with body prose along with a valid companion Proposal JSON block.
4. **Clarification First**: When management intent is underspecified.

## Domain Examples

### 1. Projects & Tracking
See `examples/project.json` for managing milestones, project status, ownership, and target completion dates.

### 2. Physical & Lab Equipment
See `examples/equipment.json` for tracking hardware models, vendors, operational status, location, and maintenance recurrence.

### 3. Legal & Industry Regulations
See `examples/regulation.json` for compliance jurisdiction, effective date, and audit review frequencies.
