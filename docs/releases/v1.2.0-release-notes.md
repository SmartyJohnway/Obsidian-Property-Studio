## English Summary

Obsidian Property Studio v1.2.0 evolves the application from an analysis and design utility into a complete, standalone, local-first **Personal Property Governance System**. Users can now author, persist, version, and enforce their own property vocabularies and schemas across entire Vaults, specific folder scopes, or individual notes—with zero cloud dependencies and a strict 100% byte-for-byte read-only Vault safety guarantee.

## 繁體中文摘要

## Highlights / 核心亮點

### 1. 📖 Personal Property Glossary (個人屬性詞彙庫) [P0]
* **3-Tier Precedence Hierarchy:** Resolution follows `System Built-in → User Override → Vault Observed Facts`.
* **User Customization:** Full CRUD management for custom property labels, guidance, descriptions, categories, and standard examples.
* **Canonical Key Immutability:** Frontmatter YAML keys remain strictly immutable across bilingual displays, preventing accidental renaming.
* **App-Local Persistence:** Safely stored outside the Vault with optimistic concurrency control (OCC) protection.

### 2. 📚 Named Schema Library (具名架構庫) [P0]
* **Reusable Governance Schemas:** Author, save, edit, and organize reusable property schemas outside the Vault.
* **Adopt from Designer:** One-click transition from Schema Designer directly into the Named Schema Library.
* **Strict Version Tracking:** SemVer tracking (`v1.0`, `v1.1`, `v2.0`) with collision protection.

### 3. ⚖️ Existing Note Reconciliation (既有筆記調和) [P0]
* **4 Distinct Property States:** Instant analysis categorizing note properties into `Matches (相符)`, `Missing (缺漏)`, `Conflict (衝突)`, and `Outside-Schema Preserved (架構外保留)`.
* **Zero Object Coercion & Complex YAML Safety:** Full preservation of complex mappings and nested structures without stringification or `[object Object]` truncation.
* **Semantic Diff & Frontmatter Preview:** Clear before-and-after diffing with one-click validated YAML frontmatter copying.

### 4. 🎯 Scope Expected Schema Assignment & Drift Diagnostics (範圍架構漂移診斷) [P0]
* **Scope-to-Schema Association:** Assign specific Named Schemas as expected standards for designated folder scopes.
* **Desired vs Actual Drift:** Comprehensive Property Health diagnostics measuring schema compliance rates, missing required properties, type mismatches, and unexpected properties.
* **Exact Path Navigation:** One-click drilldown from drift findings directly into Note Workspace with full context preservation.

### 5. 🤖 External AI Proposal Review & Companion Skill [P0]
* **Deterministic AI Proposal Review:** Human-in-the-loop workspace to inspect, validate, compare, edit, accept, or reject AI-generated schema proposals.
* **Proposal Contract 1.0 & 1.1 Support:** Full backward and forward compatibility for AI proposals with rich advisory context.
* **Independent Companion Skill:** Decoupled `obsidian-property-advisor` skill packaged for local agent environments with zero runtime dependency on the core application.

### 6. 🔄 Schema Versioning & Migration Planner [P1]
* **SemVer Recommendation Engine:** Automatic detection of breaking vs non-breaking schema changes with automated SemVer bump suggestions.
* **Planning-Only Guarantee:** Impact evaluation and step-by-step migration guide generated without mutating the user's Vault.

### 7. 📦 Governance Profile Import / Export [P1]
* **Portable JSON Packages:** Export and import complete governance setups (Schemas, Scopes, Glossary, Saved Checks, Preferences) with SHA-256 integrity verification.
* **Concrete Per-Entity Change-Set Preview:** Detailed preview displaying item-by-item actions (`新增`, `更新`, `衝突`, `移除`, `保留`, `無變更`) with instantaneous client-side toggle between Merge and Replace modes.

## Safety / 安全邊界

* **Strictly Read-Only (嚴格唯讀):** No note is created, edited, renamed, moved, or deleted. Markdown note bodies and `.obsidian/` are never touched.
* **100% Local & Offline (本機離線):** Zero external network requests, zero telemetry, zero cloud dependency, and zero required API keys.
* **No Required AI (無需任何 AI 即可完整運作):** All core analysis, schema generation, reconciliation, and drift detection execute deterministically via local Python algorithms.
* **App-Local Storage Outside Vault (Vault 外部儲存):** Governance state is persisted in `%APPDATA%\ObsidianPropertyStudio\` (Windows) or `~/.property_studio/` (macOS/Linux) with strict runtime path-containment assertions.

## Installation & Launch / 安裝與啟動

Obsidian Property Studio is a standalone Python application.

### Windows 10 & 11

```bat
py -m pip install -r requirements.txt
run_windows.bat
```

### macOS / Linux

```bash
python3 -m pip install -r requirements.txt
./run.sh
```

The application runs on loopback `http://127.0.0.1:8765`.

## Upgrading from v1.1 / 從 v1.1 升級

When launching v1.2.0 for the first time, existing preferences and Saved Relationship Checks stored in browser `localStorage` from v1.1.0 are automatically migrated to app-local storage outside your Vault. Legacy data is validated before saving and preserved in `localStorage` until the backend confirms validated readback.
