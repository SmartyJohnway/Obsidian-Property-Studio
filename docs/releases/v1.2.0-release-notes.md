## 🌟 Overview: What's New in v1.2.0

Obsidian Property Studio evolves from a Property discovery and analysis tool into a complete, local-first **Personal Property Governance System**. Users can now author, persist, version, and enforce their own Property vocabularies and schemas across entire Vaults, specific folder scopes, or individual notes—with zero cloud dependencies and a strict 100% byte-for-byte read-only Vault safety guarantee.

---

## 🚀 Key Features & Capabilities

### 1. 📖 Personal Property Glossary (個人詞彙庫) [P0]
- **3-Tier Precedence Hierarchy**: Precedence cleanly resolves from `System Built-in → User Override → Vault Observed Facts`.
- **User Customization**: Full CRUD operations for custom property labels, guidance, descriptions, categories, aliases, and examples.
- **Canonical Key Immutability**: Frontmatter keys remain strictly immutable YAML strings across bilingual presentations, preventing property renaming accidents.
- **App-Local Persistence**: Stored safely outside the Vault in the application data directory with OCC (`revision`/`etag`) protection.

### 2. 📚 Named Schema Library (具名架構庫) [P0]
- **Reusable Governance Schemas**: Author, save, edit, and organize reusable property schemas outside the Vault.
- **Adopt from Designer**: One-click workflow from Schema Designer directly into the Named Schema Library.
- **Strict Version Tracking**: Full SemVer tracking (`v1.0`, `v1.1`, `v2.0`) with collision protection.

### 3. ⚖️ Existing Note Reconciliation (既有筆記調和) [P0]
- **4 Distinct Property States**: Instant analysis categorizing properties into `Matches (相符)`, `Missing (缺漏)`, `Conflict (衝突)`, and `Outside-Schema Preserved (架構外保留)`.
- **Zero Object Coercion & Complex YAML Safety**: Full preservation of complex mappings and nested structures without stringification or `[object Object]` truncation.
- **Semantic Diff & Frontmatter Preview**: Clear before-and-after diffing with one-click validated YAML frontmatter copying.

### 4. 🎯 Scope Expected Schema Assignment & Drift Diagnostics (範圍架構漂移診斷) [P0]
- **Scope-to-Schema Association**: Assign specific Named Schemas as the expected standard for designated folder scopes.
- **Desired vs Actual Drift**: Comprehensive Property Health diagnostics measuring schema compliance rates, missing required properties, type mismatches, and unexpected properties.
- **Exact Path Navigation**: One-click drilldown from drift findings directly into Note Workspace with full context preservation.

### 5. 🤖 External AI Proposal Review & Companion Skill [P0]
- **Deterministic AI Proposal Review**: Human-in-the-loop workspace to inspect, validate, compare, edit, accept, or reject AI-generated schema proposals.
- **Independent Companion Skill**: Decoupled `obsidian-property-advisor` skill packaged for local agent environments with zero runtime dependency on the core application.
- **Proposal Contract 1.0 & 1.1 Support**: Full backward and forward compatibility for AI proposals.

### 6. 🔄 Schema Versioning & Migration Planner [P1]
- **SemVer Recommendation Engine**: Automatic detection of breaking vs non-breaking schema changes with automated SemVer bump suggestions.
- **Planning-Only Guarantee**: Impact evaluation and step-by-step migration guide generated without mutating the user's Vault.

### 7. 📦 Governance Profile Import / Export [P1]
- **Portable JSON Packages**: Export and import complete governance setups (Schemas, Scopes, Glossary, Saved Checks, Preferences) with SHA-256 integrity verification.
- **Concrete Per-Entity Change-Set Preview**: Clear preview displaying item-by-item actions (`新增`, `更新`, `衝突`, `移除`, `保留`, `無變更`) with instantaneous client-side toggle between Merge and Replace modes.
