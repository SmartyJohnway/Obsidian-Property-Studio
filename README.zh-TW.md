# Obsidian Property Studio

[English](README.md) | **繁體中文**

**無需學習 YAML，輕鬆理解、設計、填寫與治理你的 Obsidian 屬性（Properties）。**

版本 1.2.0 · 獨立本機優先 · 唯讀安全 · **絕不修改你的 Vault 知識庫**

---

## 它可以做什麼

Obsidian 的 Properties（屬性）能將零散的 Markdown 筆記轉變為可篩選、分組與查詢的結構化知識庫。**Obsidian Property Studio** 是一套 100% 在您本機運行的獨立應用程式，協助您在嚴格的唯讀安全保護下，以人類易讀的語意理解與治理筆記屬性：

| 模組 | 提供功能 |
| --- | --- |
| **1 · 知識庫與範圍 (Vault & Scope)** | 選擇知識庫資料夾並定義分析範圍（**整個知識庫**、**單一資料夾**、**多資料夾**或**單篇筆記**）。切換範圍無需重新掃描硬碟。提供掃描前後 SHA-256 雜湊比對，證明知識庫完全未被變動。 |
| **2 · 屬性探索 (Discover)** | 即時計算當前 Scope 範圍內的屬性庫存清單，並與全庫總數對照。可在右側抽屜（Drawer）深入檢視屬性儲存型態、使用次數、值變體以及格式損毀的 Frontmatter。 |
| **3 · 屬性架構設計 (Schema Designer)** | 提供結構化的**「管理對象」**（如專案、人物、書籍）與**「管理需求」**（如進度追蹤、關聯對象）確定性預設複選清單，搭配選填之自由文字說明。系統產生具備解釋理由的建議屬性清單，支援個別勾選/排除，並提供**「採用此屬性架構 (Adopt Schema)」**動作直接引導至筆記工作區或建立新 Frontmatter。 |
| **4 · 單篇筆記屬性工作區 (Note Workspace)** | 支援**即時路徑搜尋**與**全庫階層式資料夾樹目錄**（支援展開/收合全部，無 100 筆上限）。依完整相對路徑消歧義同名筆記。支援即時**語意差異比對 (Semantic Diff)**、雙語屬性標籤與唯複製 YAML 輸出。遇損毀或重複 YAML 鍵名嚴格安全中斷 (Fail-Closed)。 |
| **5 · 新增 Frontmatter (New Frontmatter)** | 依據已採用的架構動態生成輸入表單。即時預覽 YAML 內容、完成格式驗證與複製。絕不在知識庫中自動建立檔案。 |
| **6 · 安全重構規劃 (Refactor Planner)** | 嚴格受限於 Scope 範圍的**重新命名 (Rename)**、**合併屬性 (Merge)**、**數值正規化 (Normalize Values)** 與**型態轉換 (Convert Types)** 規劃。提供受控屬性下拉選單、目標名稱衝突警告，以及**「Scope 觀察值受控對照表」**。預設呈現結構化易讀摘要，純規劃性質，**絕無寫入功能**。 |
| **7 · 筆記關聯分析 (Relationships)** | 多資料夾來源範圍（Source Scope）至多資料夾目標範圍（Target Scope）關聯分析。精確區分**屬性連結 (Property Links)** 與唯讀**正文雙向連結 (Body `[[Wikilinks]]`)**，分類為四種確定性狀態：`VALID`（有效）、`BROKEN`（失效）、`AMBIGUOUS`（歧義）與 `OUTSIDE SELECTED TARGET`（目標範圍外）。 |
| **8 · 常用關聯檢查 (Saved Checks)** | 使用者主動儲存的自訂關聯分析條件（自訂名稱、備註、範圍與屬性）。安全儲存於瀏覽器本機儲存空間（`localStorage`），系統不預設任何強加的知識本體規則。 |
| **9 · 屬性健康檢查 (Property Health)** | 基於當前 Scope 範圍計算可解釋的健康指標與問題清單（缺失必要屬性、型態漂移、無效或歧義連結），並可一鍵跳轉至單篇筆記工作區深入檢視。 |
| **10 · AI 提案匯入 (AI Proposal)** | 選填功能。可匯入外部 AI Agent 產生的版本化架構提案 JSON；系統將其與您的實際知識庫結構進行驗證與比對，絕不自動套用。核心應用程式無需任何 AI。 |

## 屬性易讀詞彙層 (Property Vocabulary Layer)

Obsidian Property Studio v1.1.0 正式導入專為個人知識管理（PKM）設計的**「屬性易讀詞彙層」**：

* **雙語展示標籤：** 前端展示層以對人類友善的標籤搭配原始鍵名呈現：
  * 繁體中文介面：`狀態 (status)`、`負責人 (owner)`、`截止日期 (due_date)`
  * 英文介面：`Status (status)`、`Owner (owner)`、`Due Date (due_date)`
* **Canonical YAML 鍵名安全性：** 底層原始屬性鍵名（`status`、`owner` 等）維持不可變，輸出的 YAML 絕不進行翻譯。
* **自訂屬性安全降級：** 面對未預先收錄的自訂屬性，系統絕不臆測語意，僅忠實呈現觀察到的鍵名與庫存數據事實。
* **通用 ⓘ 引導抽屜 (Help Drawer)：** 點擊任何屬性標籤旁的 `ⓘ` 按鈕即可開啟情境抽屜，查看：
  * 屬性用途說明與使用建議
  * 典型儲存型態與建議輸入元件
  * 標準範例值
  * 當前 Scope 使用次數與全庫出現頻率
  * 知識庫中觀察到的前幾名常見實際數值

## 安全保證 (v1.1.0)

* **嚴格唯讀 (Strictly Read-Only)：** 絕不建立、修改、重命名、移動或刪除任何筆記。筆記 Markdown 正文與 `.obsidian/` 設定資料夾永遠不受侵擾。
* **絕無「套用至知識庫」按鈕：** 所有重構均為規劃與預覽性質。後端核心完全無任何修改硬碟筆記的程式碼路徑，並經自動化測試嚴格守護。
* **100% 本機離線運作：** 無任何對外網路連線、無遙測追蹤 (Telemetry)、無雲端依賴、無需註冊帳號，亦無需 API 金鑰。
* **無需任何 AI 即可完整運作：** 所有分析、架構建議與健康檢查皆由本機 Python 演算法以確定性方式執行。
* **歧義安全中斷 (Fail-Closed on Ambiguity)：** 遇歧義屬性名稱、重複 YAML 鍵名或歧義同名筆記連結時，系統一律安全中斷並給予清晰警告，絕不自行猜測意圖。
* **外部成果儲存：** 報告匯出皆儲存至使用者指定的外部目錄或瀏覽器本機儲存空間，絕不寫入 Vault。

## v1.2.0 新增功能 (工作流程閉環與本機治理架構)

Obsidian Property Studio v1.2.0 實現了屬性分析、架構設計與既有筆記治理之間的完整閉環：

* **具名架構庫 (Named Schema Library)：** 儲存、管理與版本化自訂 Frontmatter 架構規範，持久化於 Vault 外部並具備 OCC 並發衝突防護。
* **個人詞彙庫 (Personal Glossary)：** 自訂屬性顯示標籤與使用指引，系統遵循「內建 → 自訂覆寫 → 觀察現狀」三層優先權，底層 YAML 鍵名嚴格保持不可變。
* **既有筆記架構核對 (Note Reconciliation)：** 提供四態分類（`符合`、`缺漏`、`衝突`、`保留非架構屬性`），非架構屬性 100% 完整保留、絕不遺失。
* **範圍預期架構與漂移診斷 (Scope Drift)：** 為資料夾範圍綁定預期架構，即時診斷「期望 vs 實際」符合率與漂移事項。
* **架構版本遷移規劃 (Migration Planner)：** 比對架構版本差異，自動識別破壞性變更，建議語意化版號（Major/Minor/Patch）並提供逐步遷移指引。
* **外部 AI 伴隨技能 (Companion Skill)：** 於 `skills/obsidian-property-advisor/` 打包專屬技能，支援 Proposal Contract 1.0 與 1.1。
* **治理設定檔匯出匯入 (Governance Profile)：** 一鍵打包匯出具名架構、範圍綁定與個人詞彙庫，具備 SHA-256 數位簽章校驗。

* **Windows 10 (Build 19045+, 64 位元 AMD64)：** `PASS — Human Verified`（已完成完整本機瀏覽器操作與伺服器連線驗收）。

## 安裝與啟動說明

### Windows 10 & 11

```bat
:: 1. 於專案根目錄安裝相依套件：
py -m pip install -r requirements.txt

:: 2. 啟動應用程式（啟動本機伺服器並自動開啟瀏覽器）：
run_windows.bat
```

手動啟動指令：

```bat
py -m app                      :: 於 http://127.0.0.1:8765 啟動
py -m app --port 9000          :: 使用自訂通訊埠
py -m app --no-browser         :: 無介面模式（手動開啟瀏覽器）
```

### macOS / Linux

```bash
python3 -m pip install -r requirements.txt
./run.sh                       # 或：python3 -m app
```

本機伺服器嚴格僅綁定於 `127.0.0.1`（Loopback 內部網路）。如需停止應用程式，於終端機按下 `Ctrl+C` 即可。

## v1.1.0 關鍵更新亮點

1. **輕量雙語引擎（繁體中文／English）：** 支援即時語系無縫切換，偏好設定自動持久化儲存，無外部 CDN 依賴。
2. **淺色／深色雙主題引擎：** 現代高對比度深色與淺色主題，採用 CSS 設計權杖（Design Tokens）管理。
3. **正式 Scope 領域模型：** 自由聚焦於特定資料夾、巢狀子資料夾或單篇筆記，切換無需重新掃描磁碟。
4. **全庫階層式資料夾樹目錄：** 完整呈現知識庫目錄結構，支援展開／收合全部資料夾與同名筆記路徑消歧義。
5. **屬性易讀詞彙層：** 內建 PKM 屬性詞庫，提供雙語友善標籤與情境式 ⓘ Help Drawer 引導。
6. **受控數值正規化對照：** 提供 Scope 觀察值視覺化對照表，安全規劃屬性值正規化。
7. **正文雙向連結唯讀分析：** 嚴格唯讀探索與分析 Markdown 正文內的 `[[Wikilinks]]`。
8. **常用關聯檢查儲存：** 儲存自訂關聯查詢條件於知識庫外部，隨時重新載入與執行。
9. **Scope 感知健康檢查：** 嚴格依據當前選定範圍計算診斷數據與問題筆記。
10. **全套自動化驗證：** 176 項自動化測試合約與 5,000 篇筆記效能基準測試。
